# Mongoose Rail

A macOS workspace browser that organizes web apps and email accounts into separate profiles.

## Downloads

Official installers will be published on the [Releases page](https://github.com/czayas-0314/mongoose-rail/releases).

**No public DMG has been published yet.** The first public installer is being prepared and must pass distribution checks before release. The current local build targets Apple Silicon Macs; Intel and Windows installers are not currently offered here.

## About this repository

This is the public download, release-note, and issue-reporting repository. It does not contain the private development checkout, personal browser profiles, cookies, account data, credentials, or signing keys.

Downloading a release does not grant permission to change this repository or its official releases. Repository changes are controlled by the owner and explicitly authorized maintainers.

## Report a problem

Use [Issues](https://github.com/czayas-0314/mongoose-rail/issues) to report bugs or suggest improvements. Include your macOS version, Mongoose Rail version, and steps to reproduce the problem.

Do not post passwords, cookies, tokens, private emails, browser profile folders, or unredacted screenshots containing personal information. Public issues are visible to everyone.
